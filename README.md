# Dust & Dynasties

Dust & Dynasties is a Sri Lankan history game for PC that we’re building for Grade 7 to 9 students as part of our university group project.

The idea is to help students learn about the kings, kingdoms and places from their textbooks through stories, quizzes and puzzles. 

## This repository

This repository contains the project website, where visitors can learn about the game, its features, planned levels and the team behind it. The game itself is being developed separately.

Website: https://dustdynasties.lk

## Built with

- HTML
- CSS
- JavaScript
- GitHub Pages for hosting

## Pages

- Home: an introduction to the game and why we’re making it
- Features: the planned features and how the game works
- Levels: the chapter for each grade, kingdoms, tiers and activities
- About: our team, roles and why we are building it
- Play (download.html): what you need to play, the roadmap, FAQ and waitlist

The game is still in development, so some details on the website may change as we work on the project.

## Running locally

Download or clone this repository, then open `index.html` in your browser.

You can also open the project folder in VS Code and use Live Server.

## Updating the website

Changes pushed or merged into `main` are automatically deployed through GitHub Pages. Wait for the deployment to finish before checking the live website.

Keep the `CNAME` file in the repository. It connects the website to our custom domain.
